# PySpark-BigData-Analytics
this project represents a comprehensive Apache Spark (PySpark) Data Engineering &amp; Machine Learning portfolio. It covers the full spectrum of Spark capabilities: RDDs, DataFrames, SQL, Streaming, and MLlib.


Apache Spark (PySpark) Big Data Portfolio
This repository demonstrates end-to-end Big Data processing using Apache Spark. It progresses from core RDD manipulations to advanced real-time machine learning pipelines.

🚀 Key Modules
1. Core & SQL
RDD Mastery: Low-level transformations (map, filter, reduceByKey) for unstructured data processing.

DataFrame Optimization: Implementing caching strategies and UDFs to optimize SQL queries on structured data.

2. Advanced Analytics
Stock Market Analysis: Utilizing PySpark Window functions to calculate moving averages and trends on financial data.

SQL Explorations: Complex querying on FIFA World Cup datasets to derive player insights.

3. MLlib & Real-Time Streaming
Heart Disease Prediction: Trained a Logistic Regression model using pyspark.ml with feature engineering (VectorAssembler) and evaluation (BinaryClassificationEvaluator).

Streaming Inference: Built a structured streaming pipeline that ingests real-time data, applies the trained model, and outputs predictions to a console sink.

🛠️ Tech Stack
Engine: Apache Spark 3.x

Language: Python (PySpark)

Libraries: pyspark.sql, pyspark.ml, pyspark.streaming
